## 📅 120-Day Learning Roadmap

---

### 🔹 Phase 1: SQL for Data Analysis (Day 01 – 30)

#### SQL Foundations & Data Exploration
- Database schema understanding  
- Table and column exploration  
- SELECT queries  
- Data validation and profiling  
- Understanding data types  

---

#### Filtering & Conditional Logic
- WHERE clause filtering  
- Logical operators (AND, OR, NOT)  
- BETWEEN, IN, NOT IN  
- Pattern matching using LIKE  
- Handling NULL values  

---

#### Aggregation & Business KPI Analysis
- GROUP BY operations  
- COUNT(), SUM(), AVG(), MIN(), MAX()  
- HAVING clause filtering  
- Multi-column grouping  
- Business metric calculations  

---

#### Joins & Multi-Table Analysis
- INNER JOIN  
- LEFT JOIN  
- RIGHT JOIN  
- FULL JOIN  
- Self joins  
- Cross joins  
- Relationship-based analysis  

---

#### Business Segmentation & Derived Logic
- CASE WHEN statements  
- Customer segmentation logic  
- Derived business metrics  
- Conditional aggregations  

---

#### Data Cleaning & Standardization
- Handling NULL values (ISNULL, COALESCE, NULLIF)  
- Removing duplicates  
- Text data standardization  
- String functions (TRIM, REPLACE, SUBSTRING, CONCAT)  

---

#### Subqueries & Query Nesting
- Single row subqueries  
- Multi-row subqueries  
- Correlated subqueries  
- Nested business queries  

---

#### Common Table Expressions (CTEs)
- CTE structure and usage  
- Multi-step transformations  
- Recursive CTE basics  

---

#### Window Functions & Analytical SQL
- ROW_NUMBER(), RANK(), DENSE_RANK()  
- LEAD(), LAG()  
- Running totals  
- Partition-based analysis  
- Time-series comparison  

---

🎯 Phase Goal: Build strong relational data extraction and analytical SQL capability.

---
