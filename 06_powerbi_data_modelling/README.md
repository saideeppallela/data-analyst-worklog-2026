# ⚡ Power BI Data Modelling (Days 89–93)

Building a strong semantic data model using Microsoft Power BI by designing star schemas, creating relationships, implementing date tables, and understanding model optimization for business reporting.

---

# 📖 Overview

This phase focuses on the foundation of professional Power BI development by learning how enterprise data models are designed before creating reports and writing DAX.

Each day covers a practical business scenario that reflects how Data Analysts structure data models for scalable, accurate, and high-performance reporting.

The objective is to build clean, reliable, and business-ready data models that support effective analytics and future DAX calculations.

# 🎯 Learning Objectives

- Understand Fact and Dimension tables

- Create and manage table relationships
- Configure relationship cardinality and filter direction
- Build and use a proper Date Table
- Mark Date Tables for Time Intelligence
- Understand Calculated Columns vs Measures
- Review and validate complete data models
- Prepare a semantic model for DAX development
